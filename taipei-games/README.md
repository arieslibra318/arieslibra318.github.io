# 台北小遊戲合集

兩個單檔網頁遊戲，下載後用瀏覽器打開 `index.html` 就能玩，不需要安裝。

| 遊戲 | 位置 | 簡介 |
| --- | --- | --- |
| 地產大亨 | [`landtycoon/index.html`](landtycoon/index.html) | 1985–2025 年的台北 3D 大富翁 |
| 選戰60天 | [`election60/index.html`](election60/index.html) | 60 天市長選戰模擬 |

根目錄的 `index.html` 是遊戲選單。

## 地產大亨

- 56 格主線加平溪支線、貓空纜車線，岔路口可以選路。停在建成圓環或敦化圓環可以迴轉。
- 停在自己的地上加蓋一層（平房到商業大樓，泡沫時代可以升級地標大樓）。集滿整區，過路費 ×1.4。
- 整局從 1985 年走到 2025 年，依年份遇到真實時事：股市萬點、九二一、SARS、金融海嘯、COVID 疫情與紓困、升息等，會影響房價、利率和造價。
- 機場、車站港口、公用事業、捷運站、法拍中心、建設公司、證券號子、天燈廣場、纜車觀景台。
- 房貸、抵押、強制併購（含反併購與保護期）、公開拍賣、市政府委託任務、商機卡。
- 最多 4 人，可以混電腦玩家；多位真人可以輪流用同一台裝置。

3D 畫面使用 three.js r128（從 cdnjs 載入），需要網路連線。

**代碼連線 PK**：要在 claude.ai 上以 Artifact 開啟才能用，因為它依賴 claude.ai 的即時連線功能。直接用瀏覽器開檔案或放到 GitHub Pages 時，單機與同一台裝置輪流玩都正常，但「代碼連線 PK」按鈕會顯示目前無法連線。

## 選戰60天

在 2D 城市地圖上進行 60 天的市長選戰：安排拜票行程、參加活動、處理突發事件、選擇政見，爭取選民支持。勝選後可以開啟二週目。
